# rrobin-client

A full-stack web application for families and roommates to auto-assign and manage daily chores fairly. 

## Prerequisites

*   [Node.js](https://nodejs.org/) (Installing Node.js automatically includes `npm`)

## Getting Started

1.  **Clone the repository**
    ```bash
    git clone <your-repo-url>
    cd <your-repo-name>
    ```

2.  **Install dependencies**
    ```bash
    npm install
    ```

3.  **Start the development server**
    ```bash
    npm run dev
    ```

4.  **View the app**
    Open [http://localhost:5173](http://localhost:5173) in your browser to see the local development server running.
